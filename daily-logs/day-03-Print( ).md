# Day 03: Python Basics — The `print()` Function

## 🎯 Objectives
- Understand the primary output mechanism in Python using the `print()` function.
- Gain hands-on practice with syntax and play with output formatting parameters like `sep` and `end`.

---

## 💻 Concepts & Practice Covered

### 1. Basic `print()` Syntax
* Outputted simple strings and numbers to the terminal.
* Experimented with printing multiple items separated by commas.

### 2. Custom Separators (`sep`)
* Used `sep` to control what string goes between multiple printed arguments instead of the default space.
* Practiced variations like `sep="-"`, `sep=", "`, and `sep="\n"`.

### 3. Custom Endings (`end`)
* Used `end` to override the default newline character (`\n`) appended at the end of a print statement.
* Practiced chaining multiple `print()` statements onto the same line using `end=" "` or custom trailing characters.

---

## 📝 Key Takeaways
- The `print()` function is essential for displaying output and debugging code.
- Playing with `sep` and `end` provides complete control over how output is formatted in the console.
