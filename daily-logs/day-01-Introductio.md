## 📌 Key Concepts Covered

### 1. How Does a Computer Program Work?
- A **program** is a set of instructions that tells a computer's CPU (Central Processing Unit) what operations to perform.
- Executable instructions are stored in memory and processed sequentially unless controlled by logic statements.

### 2. Natural Languages vs. Programming Languages
- **Natural Languages:** Evolve naturally over time (e.g., English, Spanish) and are inherently ambiguous, flexible, and context-dependent.
- **Programming Languages:** Structurally designed, precise, and unambiguous sets of rules used to communicate instructions directly to computers.

### 3. What Makes a Language?
Every programming language consists of:
- **Alphabet:** A set of symbols used to form words and operators.
- **Lexicon (Vocabulary):** A set of valid words (keywords/reserved words).
- **Syntax:** Rules that define whether a sequence of words forms a valid sentence/statement.
- **Semantics:** The meaning or logic behind a syntactically correct instruction.

### 4. Machine Language vs. High-Level Language
- **Machine Language (Low-Level):** Binary code (`0`s and `1`s) directly executed by hardware. Fast for machines, but difficult for humans to write and maintain.
- **High-Level Language (e.g., Python, Java, C++):** Human-readable code using English-like syntax that must be translated into machine code before execution.

### 5. Translation: Compilation vs. Interpretation
- **Compilation:** The entire source code is translated into machine code all at once by a *compiler*, producing an executable file (e.g., `.exe`).
- **Interpretation:** The source code is translated and executed line-by-line by an *interpreter*. Python uses an interpreter, making debugging quicker during development.
